# DSSP Auto Logger

## Overview

DSSP Auto Logger is a Chrome Extension built to automate trainee training log submissions within the DSSP Portal.

## Current Status

🚧 Under Development

Current Phase:

- ✅ Phase 1 — Research & Planning
- 🚧 Phase 2 — Project Scaffold

---

## Objectives

- Automate repetitive logging
- Reduce human error
- Support batch processing
- Maintain auditability
- Preserve security

---

## Tech Stack

- TypeScript
- Chrome Extension Manifest V3
- Vite
- Node.js
